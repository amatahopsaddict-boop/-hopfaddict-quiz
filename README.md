# 🍺 Hopfaddict Amata - Craft Beer Millionaire Quiz WebApp

เว็บแอปพลิเคชันควิซเกมเศรษฐีความรู้เรื่องคราฟต์เบียร์ สไตล์ร้าน **Hopfaddict Amata** ออกแบบธีม Neon Pub พร้อมคำถามสุ่ม 15 ขั้น และตัวช่วย 3 ทางเลือก

---

## 🚀 วิธีการเปิดใช้งานบน GitHub Pages (ทำใน 2 นาที)

1. **สร้าง Repository ใหม่:**
   * เข้าเว็บ [GitHub.com](https://github.com) -> กดปุ่ม **New**
   * ตั้งชื่อ Repository เช่น `hopfaddict-quiz` -> กด **Create repository**

2. **อัปโหลดไฟล์:**
   * กดปุ่ม **uploading an existing file**
   * ลากไฟล์ `index.html` และ `README.md` ลงไป
   * กด **Commit changes**

3. **เปิดระบบ GitHub Pages:**
   * ไปที่เมนู **Settings** -> **Pages** (แถบด้านข้าง)
   * ตรงหัวข้อ **Build and deployment** -> **Branch** ให้เลือกเป็น `main` แล้วกด **Save**
   * รอประมาณ 1-2 นาที ระบบจะเจน URL เช่น `https://username.github.io/hopfaddict-quiz/` นำลิงก์นี้ไปทำ QR Code ให้ลูกค้าสแกนเล่นที่โต๊ะได้เลย!

## 🎮 ฟีเจอร์ของระบบ
* **สุ่มคำถามจากคลัง 50 ข้อ:** สุ่ม 5 ข้อระดับง่าย + 5 ข้อระดับกลาง + 5 ข้อระดับยาก ทำให้เล่นซ้ำได้เรื่อยๆ
* **3 ตัวช่วยสุดคลาสสิก:** 50:50, ถามนักดื่มข้างๆ และเปลี่ยนคำถาม
* **Responsive Design:** รองรับสมาร์ตโฟน, แท็บเล็ต iPad และหน้าจอทีวีในร้าน
